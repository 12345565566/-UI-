## 1. 设计令牌

### 1.1 命名陷阱（新前端必读）

`Pal.White` **不是白色**，是深蓝黑 `#0B1222`（Widgets.cs:20）。它是「卡片/按钮默认底色」的代号。旧代码里大量 `BorderColor = Color.FromArgb(196,212,230)`（浅灰蓝）是浅色主题时代残留，在现代深色底上表现为突兀的亮边（MainForm.cs:369-374、Setup.cs:163-164）。复刻时应按「霓虹强调」重写，不要照抄这些特例。

### 1.4 字体（`Fonts`，Widgets.cs:71-95）

- 字体族挑选顺序：`Microsoft YaHei UI` → `Microsoft YaHei` → 本地化「微软雅黑」→ `Segoe UI` → `Tahoma`，取系统已安装的第一个，失败回落 `Segoe UI`（Widgets.cs:76-91）。
- `F(pt)` 常规、`B(pt)` 粗体，`GraphicsUnit.Point`（Widgets.cs:93-94）。**1pt = 1.333px @96DPI**。

## 2. 控件规格

共性：全部 `SetStyle(OptimizedDoubleBuffer|AllPaintingInWmPaint|UserPaint|ResizeRedraw, true)`，矩形统一用 `(0,0,Width-1,Height-1)`（右/下各留 1px 防裁切）。所有 `OnPaint` 外层包 `try{}catch{}`，绘制异常静默降级——复刻时不需要这个行为，但要知道「绘制失败不崩」是原设计约定。

### 2.2 `ZGradientPanel`（Widgets.cs:207-287）

**公开属性**

| 属性 | 类型/默认 | 说明 |
|---|---|---|
| `Grad1` | `Color` `#070D1B` | 渐变起 |
| `Grad2` | `Color` `#0D1730` | 渐变止 |
| `GradAngle` | `float` 90 | LinearGradientBrush 角度 |
| `Background` | `Image` null | 背景图，cover 铺满 |
| `BackgroundWash` | `int` 130 | 图上一层 `rgba(4,7,16,130/255)` 暗色蒙版 |
| `Cyber` | `bool` false | 改为 `CyberTheme.DrawBackdrop` |
| `SeeThrough` | `bool` false | 先画父背景（真透明），再叠渐变 |
| `Phase` | `float` 0 | 外部每帧写入，驱动赛博背景 |

**`OnPaintBackground` 三级分支（Widgets.cs:225-286）**

1. `SeeThrough == true`：`base.OnPaintBackground` → 可选 `Background` cover + 暗蒙版 → 叠 `Grad1→Grad2` 线性渐变（Widgets.cs:231-249）。
2. `Cyber == true`：`DrawBackdrop(g,r,Phase,Pal.Accent)` → 可选 `Background` cover + 暗蒙版，**不再画渐变**（Widgets.cs:250-266）。
3. 默认：有 `Background` 则 cover + 暗蒙版，否则纯 `Grad1→Grad2` 渐变（Widgets.cs:267-283）。

**cover 算法**（三处重复，Widgets.cs:239-242）：`sc = max(rw/iw, rh/ih)`，`dw=round(iw*sc)`, `dh=round(ih*sc)`，左上角 `r.X+(rw-dw)/2` 居中，`HighQualityBicubic` + `PixelOffsetMode.HighQuality`。

**实际用法**：主页右面板同时开 `Cyber`+`SeeThrough`，并把 `Grad1/Grad2` 覆写为 **102 alpha 的半透明**（MainForm.cs:413-419）——即「背景图透出来 + 赛博光斑 + 半透明色罩」三层叠加。注意 `SeeThrough` 分支在 `Cyber` 之前返回（Widgets.cs:231），**两者同开时只有 SeeThrough 生效**，`Phase` 无效。这是源码里的优先级缺陷（推断：作者本意应是 Cyber 优先）。

### 2.3 `ZCard`（Widgets.cs:290-338）

**公开属性**

| 属性 | 默认 | 说明 |
|---|---|---|
| `Radius` | 10 | 圆角半径 |
| `Fill` | `#0B1222` | 纯色填充 |
| `Border` | `CardBorder` `rgba(accent,.373)` | 描边色 |
| `BorderWidth` | 1 | 0 = 不描边 |
| `Gradient` | false | 改用 `Grad1→Grad2` @90° |
| `Grad1/Grad2` | `#070D1B`/`#0D1730` | |
| `SeeThrough` | false | 透出父背景 |
| `CornerColor` | `#040710` | **圆角外侧**填充色，一般设成父容器色 |

**绘制顺序（Widgets.cs:309-337）**

1. `r=ClientRectangle`；`SeeThrough` → `base.OnPaintBackground`，否则全填 `CornerColor`（Widgets.cs:315-316）。这一步解决了「WinForms 无真圆角，儿角会露方块」的问题。
2. `rr = (0,0,w-1,h-1)` 求 `Draw.Round(rr,Radius)`。
3. `Gradient` ? 90° 线性渐变填充 : `Fill` 纯色填充（Widgets.cs:320-328）。
4. `BorderWidth>0` → `SmoothingMode.AntiAlias` + `Pen(Border,BorderWidth)` 沿同一路径描边（Widgets.cs:329-333）。

**实战取值**：常规卡片 `Radius 10 / 1px`；主页左卡 `SeeThrough=true, BorderWidth=0, Fill=rgba(4,7,16,.463)`（MainForm.cs:319-323）；排序页卡 `Fill=rgba(7,13,27,.62)`（MainForm.cs:548-551）；警告条 `Fill=#2A1E0A, Border=#FFB428`（MainForm.cs:493-496）。

**`OnPaint` 步骤（Widgets.cs:415-465）**

1. `SmoothingMode=AntiAlias`，`r=(0,0,w-1,h-1)`，宽高 ≤1 直接返回。
2. `!ClipCorners` → 先填 `CornerColor`（Widgets.cs:424-428）；`ClipCorners` 时由 `Region` 裁掉，不填。
3. 按上表选 `bg/bc/tc`。
4. `Draw.FillRound(g,r,Radius,bg)` → 可选 `Draw.StrokeRound(g,r,Radius,bc,BorderWidth)`。
5. 文本：
   - 单行无爱心：`Draw.T1(Text, _font, tc, r, TextAlign)`。
   - 单行 + `Heart`：`tw=MeasureText(Text)`，`hs=8`，`total=hs*2+8+tw`，起点 `sx=r.X+(r.Width-total)/2`；爱心心在 `sx+hs, r.Y+r.Height/2`；文字框 `(sx+hs*2+8, r.Y, tw+12, r.Height)` 左对齐（Widgets.cs:444-453）。
   - 两行（`SubText` 非空）：主文字框 `(+6, +10, w-12, 26)`、副文字框 `(+6, +36, w-12, 18)`，都居中（Widgets.cs:458-461）。**硬编码 y=10/36，按钮高度 <54px 时副标题被裁**（推断）。主 CTA 高度取 52~80px 正因此（Setup.cs:140、MainForm.cs:814）。

**交互/命中**：整块矩形；`MouseEnter/Leave` 切 `_hover`，`MouseDown` 左键置 `_down`，`MouseUp` 无条件清 `_down`；`Cursor=Hand`（Widgets.cs:376、409-412）。**无键盘、无焦点、无 TabStop**（`Selectable=false`，Widgets.cs:374、377），**无加载态/无禁用态动画**。任务书里的「加载态」在源码中不存在——业务侧用 `LoadingOverlay` 遮盖整个窗口代替（MainForm.cs:1319-1320）。

## 3. 视觉语言总结

1. **深底 + 霓虹强调**：背景永远在 `#040710`~`#0D1730` 区间，唯一高饱和色是主题 `Accent`；文字三档（`#E4F6FF` / `#84AECC` / `#4E6C8C`）承担全部层级，不靠字号堆叠。
2. **圆角谱系**：4（窗口按钮 hover）< 5（进度轨道）< 7（按钮/图标）< 9（方案卡/主 CTA）< 10（卡片）< 12（窗口/加载面板）< 13、15、17（药丸，半径 = 高度/2）< 18（图标方块）。**规则：方块状元素取 7~12；胶囊一律半高。**
3. **描边 = 半透明霓虹**，不是实色线。默认 `CardBorder` 是 accent 的 37.3%；强调态才升到 90%+ 并加粗到 1.4~2px。全库没有 3px 以上的常规描边（只有启动键 hover 3px）。
4. **发光（glow）用重复描边模拟**：`DrawGlowEllipse` 多层椭圆、启动键 5 层圆（线宽 i*2.3、alpha 递减）。CSS 对应 `filter: drop-shadow()` 多层或 `box-shadow: 0 0 Npx`。
5. **网格 + 扫描线**是全局氛围层：42px 网格（alpha 7%）、52px 高扫描带（峰值 alpha 16.5%）下落 41px/s、竖向网格横移 10.8px/s。它盖在所有内容**之上**（MainForm.cs:174），但 alpha 极低不挡阅读。
6. **RGB 三色光斑**：主 accent + 洋红 `#FF28D2` + 青绿 `#00FFAA`，三团径向渐变各以不同速度漂移/呼吸，构成「次级界面」的动感（CyberTheme.cs:52-81）。
7. **HUD 语汇**：四角 L 形角标（2px，呼吸 alpha 90~210）、准星十字线、旋转刻度环、雷达同心圆——都服务于「科幻仪表盘」认知，不要在新前端里删掉。
8. **排版习惯**：全部左对齐或居中，**无字距设定**；唯一例外是主 CTA「启 动」用空格拉宽（CyberHub.cs:178）。数字/版本用 `·` 分隔（`RimWorld 1.5 · 214 个模组`）。标题层级靠字重（Bold）+ 颜色，不靠下划线/背景块。
9. **动效节奏**：主界面 20fps（50ms）够用；加载遮罩 30fps。呼吸周期集中在 **3~8 秒**（Pulse k=0.9~2.2），没有 <1s 的快速闪烁——这是「不晃眼」的克制感来源。唯一短周期的是雷达波单圈 0.667s。
10. **静态尺寸基准**：窗口 1010×650（MainForm.cs:118）、标题栏 46、内容边距 16、栅格 gap 14、左栏 340、按钮高 34/36、卡片内边距 14~22。所有尺寸是 **96DPI 逻辑像素**；源码未声明 DPI 感知、未设 `AutoScaleMode`（全仓 grep 无 `DpiAware`），即在高 DPI 下由系统位图拉伸（推断）。新前端应改成响应式 + `rem`。

### 5.3 全局动画层

- **不要用 CSS 动画复刻整个 `DrawBackdrop`**：它每帧在 1010×650 上画 3 个 PathGradientBrush，CPU 很贵。建议用一张预渲染的静态暗色渐变 + 2~3 个模糊光斑（`filter:blur(80px)`，`transform:translate3d` 漂移，20~40s 周期）。
- 网格：`background-image:repeating-linear-gradient(90deg,rgba(accent,.07) 0 1px,transparent 1px 42px), repeating-linear-gradient(0deg,...)`，`background-position-x` 动画 10.8px/s；扫描带单独一个 `div`，高 52px，`linear-gradient(rgba(accent,0),rgba(accent,.165),rgba(accent,0))`，`top` 从 -52 到 100%，41.4px/s。
- 统一用 `requestAnimationFrame` 驱动 hub 的相位（源码 20fps 是性能妥协，新栈可 60fps 但呼吸频率保持不变）；`prefers-reduced-motion: reduce` 时冻结相位（源码无此处理，属改进）。
- 主题切换：源码需重启（Widgets.cs:12），新前端可即时切 CSS 变量——这是可明确改进的点。

### 5.4 复刻时的坑

1. `ClipCorners`/`CornerColor` 整套机制是 WinForms 无真圆角的补丁，CSS 里**直接删掉**，别把父色硬编码进子组件。
2. 源码里 `Pal.White`→`#0B1222` 的命名，不要照着定义 `--white`。
3. 禁用态浅色、`ZIntroPanel` 浅色卡、`#C4D6E6` 浅边按钮，三处是浅色主题残留，直接按深色规范重写（推断）。
4. `ZSchemeCard` 徽标顺序（RJW 在左）由绘制顺序导致，不是设计意图；新实现建议按「重要度」显式排序。
5. `ZTabBar` 选中态混入固定洋红 `rgba(255,60,210,.176)` 与 `ZTabBar` 下划线 `accent` 不同源；换主题时洋红不跟随（Widgets.cs:943）。新前端建议改成 `color-mix(in srgb, var(--accent) 70%, #FF32D2)`。
6. 所有坐标假设 96DPI；新栈用 rem/百分比，不要移植 46px、340px 这类硬值（可作为 `clamp()` 的基准）。

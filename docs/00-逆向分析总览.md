## 1. 它到底是什么

**RimWorld（边缘世界）整合包一键启动器**，作者「花不语」，v1.6.0。玩家解压整合包后，它在本地做四件事（见 `程序\ZOGOS使用说明.txt`）：

1. 备份玩家原有 `Config` 到整合包目录下 `ZOGOS备份\`（默认保留 10 份）
2. 用整合包自带 `Config` 覆盖
3. 写入选中的模组排序（`ModsConfig.xml`）
4. 启动 `RimWorldWin64.exe`

在此之上堆了一圈外围功能：模组体检（ModAnalyzer）、模组依赖网状图、创意工坊同步、整合包导入导出与在线分发（PackFeed）、AI 问答、PDF 报告、手机版导出、桌宠引导「苏苏」。

## 2. 技术栈判定

| 项 | 结论 | 依据 |
|---|---|---|
| 语言/框架 | C# / .NET Framework 4.x / **WinForms**，命名空间 `Zogos` | `源码\编译.bat` |
| 构建方式 | 无 .csproj，**Windows 自带 `csc.exe` 手工编译**，文件清单写死在 bat 里 | `编译.bat`、`打包两版.bat` |
| UI 技术 | **全自绘**：`OnPaint` + GDI+（`Graphics`/`LinearGradientBrush`/`PathGradientBrush`），几乎不用原生控件皮肤 | `Widgets.cs`、`CyberTheme.cs` |
| 依赖 | 零第三方库。网络用 `HttpWebRequest`/`WebClient`，压缩用 `System.IO.Compression`，JSON 用 `System.Web.Extensions`（`JavaScriptSerializer`） | bat 里 `/reference` 列表 |
| 进程模型 | 单进程 WinForms，长任务走 `BackgroundWorker` + 50ms 动画定时器（20fps） | `MainForm.cs:131` 附近 |
| 打包 | 两版：`/define:SPONSOR` 编出赞助版（多一个「外观」页），普通版 5 页 | `Edition.cs` |

## 3. 界面骨架（重写的靶子）

- 窗口：**无边框**（`FormBorderStyle.None`），客户区 **1010×650**，最小 **980×640**，圆角 `Region` 半径 12，居中启动，`WS_EX_COMPOSITED` 防闪烁（`MainForm.cs` 构造函数）。

## 7. 给协作 Agent 的约定

1. **坐标基准**：所有 Bounds 以主窗体客户区左上角 `(0,0)` 为原点，单位 DIP（WinForms 未开 DPI 缩放，默认 96dpi 下 1px = 1 DIP）。窗口固定 1010×650 起，最小 980×640。
2. **文案以 `I18n.cs` 的键值为准**，源码里 `L.T("中文")` 包裹的字符串就是最终显示文本；不要在重写时改写语气（作者文案有强烈的"玩家对玩家"口吻）。
3. **状态机只有一条主线**：`未检测到整合包 → 已就绪 → 部署中(Busy) → 已启动游戏`，其余弹窗都是旁支。重写时先把这条主线的 loading/错误/恢复做对，再补外围页。
4. **两版差异只有一个常量** `Edition.Sponsor`，重写时建议做成 feature flag 而不是两份代码。
5. 截图与实测坐标在 `逆向-实测\` 目录；引用图片请用相对路径。

## 8. 重写时必须保住的东西（照着源码核，别丢）

- 部署前**先备份、备份失败就中止**（"绝不动你的配置"是作者写进说明书的承诺）。
- 只动 `Config`，不碰 `Saves`、不碰模组文件。
- 还原备份前再自动备份一次。
- 启动器放进整合包目录后，靠识别令牌（`ZOGOS整合包标识.json` + `zogos.pack`）认路，改文件夹名/换盘符仍能识别。
- 排序方案里带「含 RJW」的成人向方案要有明显标记。
- 无边框窗口必须自己实现拖动、最小化、关闭、圆角裁剪——这些在 WinForms 里是手写代码，新框架里别当成免费功能。

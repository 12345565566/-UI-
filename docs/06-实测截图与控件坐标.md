# 06 · 实测截图与控件坐标

> 本文所有内容来自**真跑一遍程序**，不是读源码推断。截图在 `逆向-实测\` 下，可直接双击看。
> 用途：重写 UI 时拿这组图当"功能验收基线"——新界面做出来，至少这些信息和操作要一一对得上。

## 0. 怎么复现（含踩到的坑）

源码 `Program.cs` 自带三个自动化开关，不需要手动点界面：

```powershell
# 逐页渲染 PNG（会顺带写 layout.txt 控件树）
& '<工作区>\程序\Astra创世神协议.exe' --shot  '<工作区>\逆向-实测\pages'

# 控件坐标全量导出 + 同级重叠扫描 + 热切换主题测试
& '<工作区>\程序\Astra创世神协议.exe' --smoke '<工作区>\逆向-实测\smoke'

# 苏苏窗口按对话节点渲染
& '<工作区>\程序\Astra创世神协议.exe' --susu  '<工作区>\逆向-实测\susu'
```

两个坑：

1. **必须前台直接调用 `& exe ...`**。用 `Start-Process -PassThru` + `WaitForExit` 启动会一直挂着不退出、也不写文件（实测两次都这样），换前台调用立刻正常。原因未查明，重写后不需要关心。
2. 控制台打印的路径是乱码（`D:\������A1\...`），那是 exe 用系统 ANSI 代码页输出导致的**显示乱码，不影响文件落盘**——文件都乖乖写在指定目录里。
3. 三个开关都会跳过"找不到 RimWorld 整合包"的弹窗，所以随便找个空目录跑就行（本次 `--root` 指向 `程序\`，即启动器自己没有游戏本体的状态，正好把"错误态 UI"也拍下来了）。

## 2. 每页实际长什么样

### 主页 `page_0_home.png`
- 顶栏：左「ASTRA // 创世神协议」+ logo 小图标；右五个页签，选中项有霓虹描边胶囊；最右 `—` `✕`。

启动按钮：`layout_all.txt` 里那个 `ZButton[启动游戏]` 的 Bounds 是 **0,0 0×0**——因为圆环启动按钮由 `CyberHub` 自绘并用控件级命中测试接管，真正的 `ZButton` 只是零尺寸占位。**重写时别把它当普通按钮**，它是一个"环形可点区域 + 中心文字"的复合控件。

## 4. `--smoke` 报的"同级控件重叠"怎么理解

每个页面都报 `重叠字符数=1929`，罪魁是主页那 7 个 `Label {X=0,Y=0,Width=100,Height=23}`（`当前状态`/`当前排序方案`/`未选择`/`模组数量`/`-`/`运行状态`/`就绪`）。它们**全挤在 (0,0) 从没被布局过**——这就是主页警告条里三行字叠在一起的原因（截图可见：三行提示文字压成两团）。

顺带：`页面 N 赞助按钮处最上层 = (null)`，说明那个位置的命中测试返回空，赞助按钮在自检路径下并不存在（它挂在右面板里，`RebuildUi` 之后才建）。

**这两条是原实现的真缺陷，不是截图工具的问题。** 重写时按"错误提示三行不叠、赞助入口始终可点"来验收即可。

## 5. 普通版 vs 赞助版（实测差异）

| 项 | 普通版 | 赞助版 |
|---|---|---|
| 页签数 | 5（无「外观」） | 6 |
| 顶栏标题 | `ASTRA // 创世神协议` | 同样（`Edition.Title` 是窗口标题 `感恩的心❤，感谢有你！`，画在顶栏里的字不变） |
| 主题色可切 | 否，强制 0 号赛博青 | 是，4 套 |
| 背景图/GIF/视频 | 否 | 是 |
| 主页布局 | 相同 | 相同 |

赞助版是我用 `源码` 里 `打包两版.bat` 的 csc 命令行加 `/define:SPONSOR` 现编的（产物未留在工作区，只留了截图与 layout）。编出来能跑，说明**当前源码是可编译的**——`01` 文档里"`编译.bat` 可能已失效"的疑虑，至少在 `打包两版.bat` 这条链路上不成立。

## 3. 怎么调（不用改代码结构）

`MinFrameFx.cs` 顶部：

```csharp
public static bool Enabled = true;   // 整层开关，改 false 就全消失
public static bool Animate = true;   // false = 不呼吸（低配/自检用）
```

具体数值都在各 `Draw*` 方法里，按方法分块：

- `Paint()`：描边粗细/alpha 区间、内圈内缩量
- `DrawCorners()`：`L`=角标长度、`I`=距边内缩、`G`=跳过圆角曲率的起点
- `DrawCursorGlow()`：`R`=光斑半径、alpha
- `DrawScanlines()`：周期 4px（改这里的位图尺寸即可）、alpha
- `DrawVignette()`：`D`=渐隐宽度、alpha

改完执行 `编译极简版.bat`，约 5 秒出 exe。

## 4. 想再加效果，有三个落点

1. **加在框上**（推荐）：在 `MinFrameFx.cs` 里新写一个 `DrawXxx(Graphics g, float w, float h)`，在 `Paint()` 末尾调用。此时 `g` 已被裁剪成窗口圆角，且坐标系是**逻辑坐标**（1010×650 基准，渲染时整体乘 UiScale），直接按逻辑像素写就行。
2. **加在内容层**：`MainForm.PaintContent()` 里，在元素树之前/之后插绘制。注意这里画的东西会被 `FrameFx` 盖住（它在最外层）。
3. **加真·后处理**（色差/辉光/拖影这类需要读像素的）：`MinControls.cs` 的 `LayeredForm.Render()` 里，`PaintContent(g)` 之后、`Push()` 之前，对 `bmp` 做一遍逐像素或 ColorMatrix 处理。注意 1313×845 的位图逐像素循环会明显吃 CPU，优先用 `ColorMatrix` / `TextureBrush` / `GraphicsPath` 这类走 GDI+ 硬件路径的做法。

**性能约束**：整窗重绘 = 新建一张 1313×845 32bpp 位图 + GDI+ 全量绘制 + `UpdateLayeredWindow`。当前呼吸是 90ms（约 11fps），鼠标移动限频 60ms。要提到 30fps 之前先测 CPU，别直接改。

## 5. 构建与运行

```
编译极简版.bat            → 编 GUI 一个产物，输出 程序-极简\Astra创世神协议.exe
启动-极简版.bat           → 检测旧实例 → 编译 → 启动（带 --root 真实环境\rim）
启动-极简版.bat -nobuild → 跳过编译直接启动
启动-极简版.bat -bare    → 不指定整合包，测未识别状态
```

`编译极简版.bat` 的实质是：

```
csc /target:winexe /main:Zogos.Program /win32icon:app.ico /out:"..\程序-极简\Astra创世神协议.exe" @build_gui.rsp
```

**要加/删源文件，改 `源码\build_gui.rsp`**（一行一个 `/reference:`、`/resource:` 或 `xxx.cs`，相对路径按 `源码\` 解析）。不要往 bat 里塞文件清单。

## 7. 继续干活前必须知道的坑

1. **分层窗口放不了 Win32 控件**。整窗是 `WS_EX_LAYERED` + `UpdateLayeredWindow`（`MinControls.cs:15-108`），任何 `Label`/`TextBox` 放上去都不显示。一切自绘，命中分发靠 `MainForm.Pick(ToLogical(...))`。
2. **旧 exe 开着就编不进去**：csc 代码全过，最后报 `CS0016 未能写入输出文件…另一个程序正在使用此文件`。先关窗口，或让 `启动-极简版.bat` 帮你关。
3. **`.bat` 必须 CRLF + UTF-8 无 BOM**。用文本工具写出来的 LF 文件会被 cmd 切碎执行（表现为 `%~dp0` 为空、`pause` 卡死、日志 0 字节）。
4. **`源码\` 目录 PowerShell 写不进去**（继承 ACE `Everyone:(DENY)(S,DC)`），`WriteAllText` 会报访问被拒；但 read/write/edit 工具能写。中间产物写工作区根目录。
5. **`--shot` 是真屏幕抓图**，不是离屏渲染：上层窗口（DSH、截图工具）会被拍进图里。看截图判断 UI 时注意。
6. **csc 长命令行会炸**（`CS1562` 看起来像 /out 丢失，实际是 51 个带引号的源文件参数被吃）。所以用 rsp 文件。
7. **界面缩放默认 130%**（`Settings.UiScalePct`），窗口物理尺寸 1313×845，逻辑坐标仍是 1010×650。写绘制代码一律用逻辑坐标，`Render()` 会自动乘。

# 07 · 前后端映射契约表

**范围**：`MainForm.cs` / `Setup.cs` / `MobileExportForm.cs` 三个文件里**所有**事件订阅点（`+=`），逐个追到真实处理方法。

**约定**
- 事件签名统一是 `EventHandler` → `void (object sender, EventArgs e)`；匿名 lambda 一律写作 `delegate(object s, EventArgs e)`（`MobileExportForm.cs` 里写成无参 `delegate {}`）。下表「参数」列写的是**业务方法的参数**，不是事件参数；业务参数全靠闭包捕获（如 `idx`、`mode`、`card.Scheme`）。
- 「定义位置」前半是方法定义行，括号里是订阅行。
- 匿名 lambda 没有方法名，C# 方法全名列填它实际调用的方法 + `(lambda)`。
- 无返回值的方法列 `void`；`DirOrFile` / `DefaultDir` 是唯一两个有返回值的。
- 标「未确认」的是我无法从这三个文件里确认的行为（跨文件或需运行验证）。

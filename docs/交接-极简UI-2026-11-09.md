## 3. 构建与部署

### 标准编译命令（在 `源码\` 目录下执行）

```
taskkill //IM "Astra创世神协议UI Up.exe" //F
"C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" //nologo //codepage:65001 //target:winexe //main:Zogos.Program //win32icon:"<工作区>\源码\app.ico" //out:"<工作区>\程序-极简\Astra创世神协议UI Up.exe" @build_gui.rsp
```

- **exe 被占用时必须先 taskkill**，否则 csc 写不进去。
- `build_gui.rsp` 是权威编译清单（源码文件 + 嵌入资源）。`编译.bat`、`打包两版.bat` 里的清单已与它同步。
- 语法约束：**C# 5**——禁止字符串插值 `$""`、`?.`、`nameof`、表达式体成员。编译器是 .NET 4.x 自带 csc，零第三方依赖。
- 编译警告（CS0108/0168/0219 等）全是历史遗留，可以忽略；出现 error 才是真问题。

### 自检（每次改完 UI 必跑）

```
cd /<工作区>/程序-极简
./Astra创世神协议UI\ Up.exe --shot "<工作区>\新UI-极简\并轨截图NN"
```

会输出：5 个页面截图 + 各覆盖层截图 + **弹窗预览**（`dlg_error/dlg_warn/dlg_info` 三档装饰条、`dlg_moddetail` 模组详情、`dlg_wssync` 工坊同步）+ `layout.txt` + `trace.txt`。苏苏覆盖层抓的是「目录节点 8 选项展开」状态（专门验证选项不溢出气泡）。

其他自检入口（Program.cs 里）：
- `--smoke <dir>`：无窗口布局自检 + 控件重叠扫描
- `--susu <dir>`：旧版苏苏窗各节点渲染 PNG
- `LayeredForm.SavePreview(path)`：任何分层窗强制渲一帧存 PNG（**注意：必须用 `IntPtr h = Handle;` 强制建句柄，`CreateControl()` 对不可见窗口不建句柄**）

## 4. 渲染架构（最重要的一节）

### 分层窗口管线（MinControls.cs · LayeredForm）

```
PaintContent(g)  →  直接画进 DIB 位图 _cache  →  UpdateLayeredWindow 直推上屏
```

- **DIB 直通零拷贝**：GDI+ 直接画进 `CreateDIBSection` 分配的共享内存（`_cache` 是包裹这块内存的 Bitmap），推送时 `_memDC` 已选好位图，一次 `UpdateLayeredWindow` 完事。不要再引入 `GetHbitmap`（每帧全图转换，曾经的卡顿大头）。
- **特效层默认关闭**：`MinFrameFx.cs` 的 `FrameFx.Enabled = false`（呼吸框是卡顿主源）。开启时才会走 `_base` 内容位图 + `CompositeFx()` 合成双缓冲路径；`FxEnabled=false` 时 `_base` 不分配、`RenderFxOnly()` 直接返回。想恢复呼吸框改回 true 即可（TODO：以后做成设置项）。
- 只有状态变化才 `Render()`，没有任何空转的定时器。
- **整窗透明度**：`PushAlpha`（0-255，乘在逐像素 alpha 上，默认 255）——`MenuPopup` 的展开动画（滑落 10px + 淡入 120ms）就是靠它；做其他弹窗动画直接复用。

### 逻辑坐标与 UI 缩放

- 布局代码全部用**逻辑坐标**（主窗 1010×650），渲染时乘 `LayeredForm.UiScale` 放大（默认 130%）。
- `SetLogicalSize(w,h)` 设窗口大小；`Lw/Lh` 是逻辑宽高；鼠标命中前用 `ToLogical(p)` 换算。
- 独立弹窗（MinDialog / ModDetailForm / WorkshopSyncForm）同样覆盖 `ContentScale => UiScale`，跟随缩放。

### 像素字体纪律（会踩的坑）

`T.F(px)` / `T.B(px)` 返回的是**缓存共享字体，绝对不能 Dispose**（历史上 Dispose 导致过全局字体句柄损坏）。自己 `new Font` 出来的（如 ElLogView 的 Consolas）才归自己管。

### El 元素体系

- `El.Host` 类型是 **`LayeredForm`**（已从 MainForm 泛化），任何分层窗都能复用全部 El 零件。需要 MainForm 专有功能（Toast/MousePos/RelayoutRight）的地方用 `Host is MainForm` 强转。
- 现有零件：ElBtn / ElText / ElCard / ElInput（单行，支持粘贴）/ **ElInputMulti**（多行，支持粘贴/滚轮）/ ElCheck / ElLogView（可选中复制，`MaxLines` 可调）/ ElFold / ElRail / ElPackList / ElConfirm / ElToast / MenuPopup（支持 `AddLabel` 灰色说明行、展开动画）/ ElLaunch / ElSusu 等。
- 分层窗口**不能放任何 Win32 真控件**（不会显示），只能自绘。

## 5. 弹窗体系（MinDialog.cs）

**所有 `MessageBox.Show` 已全局替换为 `MinMsg.Show`**（69 处，签名兼容，按钮语义一致：Enter=确定/是，Esc/×=取消，「是/否」无 ×）。

装饰条颜色 = 危险等级，由 MessageBoxIcon 自动映射：
- Error/Stop/Hand → **红条**（报错）
- Warning/Exclamation → **黄条**（启动流程确认：路径含中文/体检/环境问题）
- Question/Information/无 → **青条**（普通提示）

新弹窗直接用 `MinMsg.Show(this, "正文", "标题", MessageBoxButtons.X, MessageBoxIcon.Y)`，不要再 new Form。

## 11. 常见维护操作速查

**加一个新弹窗**：`MinMsg.Show(this, text, caption, buttons, icon)`，完了。
**加一个自定义弹窗**：继承 `LayeredForm`，仿 `ModDetailForm`（BuildButtons→LayoutAll→PaintContent）。
**加设置项**：Core.cs 三处（字段 / Load 的 case / Save 的 AppendLine）+ MinSettings 里加行。
**改界面文字大小**：一律用 `T.F(px)/T.B(px)` 像素字号；布局用逻辑坐标，缩放自动跟随。
**主窗加元素**：对应页面 Build 方法里 `AddEl(_xxEls, new ElBtn(...))`，布局在 LayoutHome/DoLayout。
